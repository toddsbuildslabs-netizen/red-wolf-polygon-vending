# 🐺 The Red Wolf on Polygon
*Automated On-Chain Vending Machine & Community Follower Portal*

## Overview
**The Red Wolf** is a decentralized public-good initiative built on **Polygon PoS**, designed to merge wildlife conservation advocacy with frictionless, automated token distribution. The protocol operates completely autonomously 24/7, providing instant token acquisition and verified community rewards while routing a portion of transactions to conservation foundations.

## Core Features
* **Automated Token Vending (`buyTokens`):** Instant native-currency-to-token purchases with built-in split logic (directing funds securely to operational maintenance and charity foundations).
* **Sybil-Resistant Claim Portal (`claimFreeTokens`):** Secure cryptographic verification (`validClaimCodes`) to reward verified community supporters and followers safely.
* **Polygon PoS Optimized:** Engineered for ultra-low gas fees and high-speed execution, making micro-transactions accessible to a global audience.
